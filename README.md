# ZapretDrum

Удобная графическая оболочка для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
(обход DPI-блокировок Discord и YouTube на Windows).

Возможности:
- 🚀 Запуск и остановка любой стратегии (`general.bat`, `general (ALT11).bat` и т.д.) одной кнопкой
- 🎯 Автоподбор: приложение само перебирает все стратегии, проверяет доступность Discord/YouTube и находит лучшую
- ⬇️ Обновление zapret до последней версии с GitHub одной кнопкой (с сохранением ваших пользовательских списков доменов)
- 📦 Автоматическая первая установка — ничего скачивать вручную не нужно

> ⚠️ Работает только на Windows — сам zapret использует Windows-компоненты
> (`winws.exe`, драйвер WinDivert). На старте приложение запросит права
> администратора (UAC) — они нужны для управления процессом и драйвером.

## Запуск из исходников

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

При первом запуске приложение предложит скачать последнюю версию zapret
с GitHub — просто нажмите кнопку на странице «Обновление».

## Самообновление приложения (как у ArnUnlock)

ZapretDrum умеет обновлять сам себя одной кнопкой в «Настройках» — без
похода в браузер и без переустановки вручную. Для этого нужно один раз
всё настроить:

### 1. Создайте свой репозиторий на GitHub

Например `github.com/ваш_логин/ZapretDrum` (публичный, чтобы Actions и
скачивание релизов работали бесплатно). Залейте туда содержимое этой
папки.

### 2. Впишите свой логин в код (одна строка)

Откройте `core/paths.py`, найдите:

```python
APPUPDATE_GITHUB_OWNER = "YOUR_GITHUB_USERNAME"
APPUPDATE_GITHUB_REPO = "ZapretDrum"
```

Замените `YOUR_GITHUB_USERNAME` на свой логин на GitHub. Закоммитьте и
запушьте это изменение.

### 3. Выпускайте новую версию тремя командами

Каждый раз, когда я (или вы сами) что-то поменяли в коде и хотите, чтобы
это дошло до всех, кто уже установил ZapretDrum:

```bash
git add .
git commit -m "Что-то починили"
git tag v1.0.1
git push origin main --tags
```

Дальше всё происходит **автоматически** на серверах GitHub (файл
`.github/workflows/release.yml`):
1. Собирается `ZapretDrum.exe` (PyInstaller)
2. Собирается установщик `ZapretDrum-Setup.exe` (Inno Setup)
3. Публикуется GitHub Release с этим файлом и версией из тега

Через несколько минут после `git push --tags` релиз уже готов — ничего
руками собирать не нужно, GitHub Actions делает это в облаке на
виртуальной Windows-машине.

### 4. Что видят пользователи

В «Настройках» → «Обновление ZapretDrum» — кнопка «Проверить обновления
ZapretDrum». Если вышла версия новее установленной, появляется кнопка
«Обновить ZapretDrum»: она скачивает `ZapretDrum-Setup.exe` из вашего
последнего релиза, запускает его в тихом режиме (без окон мастера),
приложение закрывается и само открывается заново уже в новой версии.

> Важно: версия каждого релиза берётся из git-тега (`v1.0.1` → `1.0.1`),
> а не из файла `VERSION` в репозитории вручную - CI сам подставляет
> правильное значение при сборке. Просто ставьте новый тег для каждого
> релиза, увеличивая номер (`v1.0.1`, `v1.0.2`, `v1.1.0`...).

## Сборка полноценного установщика (чтобы скинуть друзьям)

Если хотите файл в духе обычных программ — с мастером установки, выбором
папки и ярлыком на рабочем столе — соберите инсталлятор:

1. Один раз установите **Inno Setup** (бесплатно): https://jrsoftware.org/isdl.php
   (при установке ничего менять не нужно, все настройки по умолчанию)
2. Запустите:
   ```bash
   build_installer.bat
   ```

Скрипт сам соберёт `ZapretDrum.exe` и упакует его в установщик. Результат:

```
installer\Output\ZapretDrum-Setup.exe
```

Это один файл — его и отправляйте друзьям. При запуске он покажет
обычный мастер установки Windows: свой значок, приветствие, выбор папки,
ярлык на рабочем столе (по желанию), пункт в меню «Пуск», индикатор
прогресса копирования файлов, и добавит программу в «Установка и
удаление программ» для аккуратного удаления - все стадии, как у обычных
Windows-программ.

## Сборка одного .exe без установщика

Если инсталлятор не нужен и достаточно самого файла:

```bash
build_exe.bat
```

Готовый файл появится в `dist\ZapretDrum.exe`. Его можно переносить на
любой Windows-компьютер без установленного Python, но для распространения
среди других людей лучше использовать `build_installer.bat` — так
привычнее и приятнее.

Если увидите ошибку `"pyinstaller" не является внутренней или внешней
командой` — значит используется старая версия `build_exe.bat`. Текущая
версия вызывает PyInstaller через `python -m PyInstaller`, что работает
даже если папка `Scripts` не добавлена в PATH.

## Структура проекта

```
ZapretDrum/
├── main.py                 # точка входа, запрос прав администратора
├── VERSION                   # версия приложения (для сборки/самообновления)
├── build_exe.bat            # сборка dist\ZapretDrum.exe
├── build_installer.bat       # сборка exe + установщик одной кнопкой
├── .github/workflows/
│   └── release.yml            # автосборка + публикация релиза по git-тегу
├── installer/
│   └── setup.iss              # скрипт Inno Setup (мастер установки)
├── assets/
│   └── icon.ico                 # иконка приложения и установщика
├── core/
│   ├── app_version.py          # версия самого ZapretDrum
│   ├── app_updater.py            # самообновление ZapretDrum
│   ├── paths.py             # пути к данным приложения, константы
│   ├── state.py              # сохранение настроек (json)
│   ├── installer.py          # скачивание/установка/обновление с GitHub
│   ├── strategies.py          # поиск доступных .bat стратегий
│   ├── process_manager.py     # запуск/остановка winws.exe
│   ├── tester.py               # автоподбор лучшей стратегии
│   └── updater.py              # проверка версии
└── ui/
    ├── theme.py                 # тёмная тема (QSS)
    ├── widgets.py                # переиспользуемые виджеты
    ├── workers.py                 # фоновые потоки (чтобы GUI не зависал)
    └── main_window.py             # окно приложения и все страницы
```

## Где хранятся данные

`%LOCALAPPDATA%\ZapretDrum\`
- `zapret\` — сама распакованная программа zapret
- `state.json` — избранная стратегия, версия, история автотестов
- `user_lists_backup\` — бэкап ваших пользовательских списков доменов при обновлении

## Антивирус

Как и оригинальный zapret, `winws.exe` и драйвер `WinDivert64.sys` иногда
ложно детектируются антивирусом (это стандартное поведение для программ,
работающих с сетевыми пакетами на низком уровне). При проблемах со
скачиванием — как и в оригинальном репозитории — попробуйте временно
отключить антивирус на время распаковки и добавить папку
`%LOCALAPPDATA%\ZapretDrum` в исключения.
